# 宇宙银河机甲 · 网页版

体素风机甲动作游戏的 **单文件 HTML 可玩版**。无需构建、无需服务器，双击即可离线游玩（字体联网加载，断网时回退系统字体）。

## 在线游玩

- 正式版：<https://mmb9w48ff7.github.io/GalaxyMecha-Web/> （需在仓库 Settings → Pages 中开启）
- 仓库内直接下载：[index.html](index.html) / [index_test.html](index_test.html)

## 两个文件

| 文件 | 说明 |
|---|---|
| `index.html` | 正式版，完整游戏流程 |
| `index_test.html` | 测试版，屏幕左侧带测试面板（加资源、无敌、生成敌人、跳关卡、帧率、全屏等调试入口） |

## 玩法概览

- 太空第三人称 3D 战斗：球形太空战场，无地面；左半屏摇杆飞行，右半屏拖动转视角，自动锁定。
- 6 台体素 Q 版机甲（S / SS / SSR / SSSR 四档）、6 位驾驶员，可分别召唤。
- 3 个章节（每章 6 个星域，含 6 种目标 + 首领）、危险等级 1~10、无尽模式、每日挑战。
- 1080 张技能卡牌 + 天赋芯片 + 元素反应 + 卡牌进化；工坊研发、每日登录、任务与成就。
- 操作：手机左下拖动转向、右下开火/加速；电脑 WASD 转向、空格开火、Shift 加速。
